AI Agents · MCP

Limits and honest claims.

Rate
30 tool calls per minute per token. The MCP handshake and tools/list are free. R2
Triggers
Up to 20 active timers and alarms per caller. A fire is 1 s to 30 days out; intervals are 60 s or more. R2
Credits
Each anchor spends one testnet log credit: two per stopwatch measurement, one per timer or alarm fire. Reads and verification are free. R2
Webhooks
Optional webhook_url on timer_set and alarm_set. Standard-Webhooks headers, HMAC-SHA256 signature with a per-caller secret returned once. Destinations are DNS-pinned and allow-listed. R2R13
Blocks
Blocks mint only on writes, so consensus now goes stale on an idle chain. R9
Network
Anchored on the Clockchain anchoring gateway: testnet, one validator. Hash, block anchor and block time are real and verifiable with no key. Multi-validator attestation starts at mainnet. R1R9
Evidence
Not yet a court-of-law evidentiary claim. R1
Packages
The @clockchain packages are not on npm yet. Use the hosted endpoint, or clone and build the repo. R7
